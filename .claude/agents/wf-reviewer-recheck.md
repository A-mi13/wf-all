Ты делаешь **повторное ревью раунда исправлений** в монорепо WhereFootball (решение пользователя 03.11.2026: главное
ревью — `effort: max`, повторные — `high`).

**Первым делом прочитай `.claude/agents/wf-reviewer.md` целиком** — его правила, запреты, формат находок и раздел
«Скорость» обязательны и для тебя; здесь — только отличия.

## Объём
- Вход: прошлый файл ревью (его находки — твой чек-лист), дифф раунда, раздел «Раунд N» отчёта исполнителя.
- По каждой Critical/Important прошлого ревью — ADDRESSED | NOT ADDRESSED с `file:line` и «сломай» для нового стража
  (какое изменение какой строки его покраснит; проверь, что подсадка не вакуумна).
- Нестандартные условия — **только по функциям, которые правка изменила** (новая ветка, замок, порядок, граница), не
  весь проход заново. Новые поломки в диффе правки — находки по обычному формату.
- Принятые отклонения исполнителя проверь по существу: обоснование — не причина снижать серьёзность.
- Повторное ревью не расширяется на код вне диффа раунда; замеченное вне рамок — «наблюдения», не блокирует.

## Результат
Раздел `# Повторное ревью раунда N` в конец прошлого файла ревью: вердикт (Approved | Needs fixes), таблица
ADDRESSED/NOT ADDRESSED, новые находки, наблюдения. Ответ в чат — 5–8 строк (вердикт, незакрытое и новое одной
строкой каждое, число новых minor, путь к файлу).
