# Админка (`apps/admin`)

Спека — `docs/superpowers/specs/2026-10-06-staff-admin-geo2-design.md` §9. Общие правила фронтов — `frontend.md`.

- **Структура:** `src/app/` — роутер, провайдеры, сессия, права, guard'ы; `src/ui/` — набор компонентов; `src/features/<раздел>/` — экраны; `src/api/` — клиент и мутации; `src/i18n/` — язык.
- **Компоненты** — только из `src/ui` (импорт `../../ui`); своих кнопок, полей, модалок, таблиц и состояний в `features` не заводить. Заглушки экранов до Task 13–15 — `src/app/stubs.tsx` (`PageStub` — вне каркаса, `SectionStub` — раздел внутри AppShell).
  - Каркас — `AppShell` (`src/ui/shell`), его ставит роутер для стадии `active` (`ActiveShell` в `router.tsx`): меню из `NAV` (`src/app/nav.ts`), карточка «имя, роль · города» (`useAccountCard`, названия городов — `GET /v1/geo/cities?ids=`), переключатель языка в меню профиля, «Выйти» (`POST /v1/staff/auth/logout`, затем `session.afterLogout()` — вход без `return`: следующий сотрудник не попадёт в чужой раздел; `401` на выходе — так же; истёкшая сессия — по-прежнему с возвратом). Флаг «без return» живёт только во вкладке, где нажали «Выйти»: другие вкладки после 401 уходят на вход с `return` — осознанно, общий выход по вкладкам (BroadcastChannel) — по необходимости). Ширина < `breakpoint-mobile` — нижний таббар (до 4 разделов, открытых на телефоне) и «Ещё» (шторка: карточка, все разрешённые разделы, язык, «Выйти»). Счётчик пункта — проп `counts` по `path` (число) и `NavItem.countLabelKey` (подпись для читалки, `{count}`); запрос счётчика «Подтверждения» — фоновый, `...background()` (Task 15).
  - **Новый раздел:** путь — `paths.ts`; маршрут — ребёнок `shellRoute` в `router.tsx`; пункт в `NAV` — `{ path, labelKey, permission, icon, desktopOnly? }`. `permission` — ключ каталога (`null` — своё, любому активному). Пункта без права в меню нет, прямой адрес (и вложенные `/раздел/…`) — `ForbiddenState` сам AppShell; `desktopOnly: true` — на телефоне `DesktopOnlyState` (в таббар не попадает, в «Ещё» есть). Экран раздела проверку права не дублирует; страница начинается с `PageHeader` (единственный `h1`), вкладки — `Tabs` (управляемые, значение — search-параметр; счётчик — `count`, имя вкладки «Входящие 3»).
  - Списки — `DataTable` (`columns`, `rowKey`, данные — `{...infiniteTableProps(useInfiniteQuery(…))}` со страницами `{items, next_cursor}` и `getNextPageParam: (p) => p.next_cursor ?? undefined`): поиск (`search`, запрос уходит после паузы `SEARCH_DEBOUNCE_MS`; запоздавшее эхо отправленного значения набор не затирает), чипы (`chips`), раскрывающийся фильтр (`filters: { content, active }` — поля экрана; число заданных — в имени кнопки), сортировка (`sort` + `onSortChange`), «Показать ещё», «Показано N», «Сбросить фильтры» (`dirty` + `onReset`); сам показывает скелетон, пусто (`empty` — своё пустое без фильтров, «Очередь пуста»), ошибку с кодом и «Повторить» (`retrying` — занята, пока идёт перезапрос). Роли строк и ячеек — явные: на телефоне строки-карточки, подпись столбца в ячейке видна и слышна. Фильтры и сортировку держит экран (search-параметры маршрута).
  - Состояния: `EmptyState`, `ErrorState` (код для поддержки + «Повторить»), `LoadingRows` (скелетон), `OfflineBanner` (`useOnline`; стоит в AppShell), `ForbiddenState`, `DesktopOnlyState`, `RateLimitedState` (`retryAfter` из `ApiError`, отсчёт; повторный 429 с тем же значением — `key={error}`), `PendingApprovalNotice` (после `202`), `ConnectionErrorState` (стадия `error` сессии).
  - Примитивы: `Button` (`variant`: primary | secondary | danger | danger-outline | link; `size="lg"` — вход; `loading`; по умолчанию `type="button"`), `StatusChip` (`tone`, текст обязателен), `CountBadge` (0 не рисуется, >99 — «99+»), `Avatar` (инициалы, декоративный).
  - Формы — `Form form={useForm()} onSubmit={(v) => m.mutateAsync(v)}` и поля `TextField`, `PasswordField`, `SelectField`, `MultiSelectField` (`searchable`, `onSearch` — поиск на сервере), `CheckboxField`, своё поле через `Controller` + `FieldError`. Ошибка `onSubmit`: `validation.failed` → `body.<поле>` раскладывается по полям (текст `ui.field_errors.<код>`), остальное — `FormError` (`errors.<код>`, откат на `errors.internal`). Особые случаи (`attempts_left`, 429) — `onError` экрана, вернуть `true`. Текст ошибки по коду вне формы — только `useErrorText()` или `<FormError error={…} />`, своих откатов не писать.
  - `OtpInput` — код второго фактора: `onComplete(code)` один раз на полный ввод, после ошибки — `ref.current.reset()` (очистка и фокус; пока ячейки `disabled` — фокус встанет, когда их включат); резервный код — обычный `TextField`.
  - Оверлеи `Modal`, `Drawer` (панель справа), `Sheet` (шторка снизу), `ConfirmDialog` (`confirmWord` — слово или почта, точное совпадение): `open` + `onClose` у экрана, фокус-ловушка, Esc (только верхний), возврат фокуса на открыватель (запоминается до `autoFocus` содержимого), блок прокрутки — внутри. `dismissible={false}` / `loading` — пока идёт запрос. `ConfirmDialog` на узком экране сам становится шторкой (`useIsMobile`, порог — токен `breakpoint-mobile`).
  - Тосты — `useToast().success|info|error(текст, { action })`: успех и справка исчезают через 8 с (`TOAST_HIDE_MS`, пауза при наведении и фокусе), ошибка — только руками. Живые области постоянные и без ролей (`aria-live` polite/assertive): `getByRole('alert')` в тестах экранов находит только их ошибки. Порядок: успехи и справки — над ошибками, внутри области — по появлению. При открытой модалке тосты входят в цикл Tab; закрыли тост с фокусом (кнопкой или `dismiss(id)`) — фокус туда, откуда пришли, иначе на верхний диалог по стеку оверлеев. `ToastProvider` стоит в `AppProviders`.
  - `Form` гасит повторную отправку, пока идёт первая; ошибка не от API — `errors.internal` на экране и `console.error`.
  - CSP admin-api (`style-src 'self'`): во всём `src` (кроме тестов) нет атрибута `style`, `<style>`, `dangerouslySetInnerHTML` и записи в `element.style` — только CSS Modules; цвета — только `var(--wf-color-*)`. Страж — `src/ui/csp.test.ts`.
- **Права** — только из `me.permissions` (`useCan`, `useDecide`, для многих прав разом — `usePermissionCheck` из `src/app/session.tsx`), не по роли: `allow` — сразу, `scoped` — в `me.city_ids`, `dual` — «можно запросить» (`useDecide` → `needs_approval`). Раздела без права нет в меню (`src/app/nav.ts`), прямой адрес — `ForbiddenState`. Решает всегда сервер.
- **Тексты** — только `messages/{ru,en}.json`, en — перевод, не пустая строка (D21). Подписи прав — `permissions.<ключ>`, действий подтверждений — `approvals.actions.<действие>`, ошибок — `errors.<код>`; стражи — `src/i18n/labels.test.ts`, `error-codes.test.ts`.
- **Пути** — только константы `src/app/paths.ts`; новый раздел — путь там, маршрут в `src/app/router.tsx`, пункт меню с правом в `nav.ts`.
- **Запросы** — `useApi()` (openapi-fetch, тот же origin, `credentials: 'same-origin'`). Клиент сам ставит `X-WF-Admin` на мутациях и бросает `ApiError {status, code, fields, retryAfter, attemptsLeft}` на любой не-2xx; `401 auth.reauth_required` — ждёт разблокировку (`reauthBus`) и повторяет запрос. Данные ответа — `unwrap(api.GET(…))` (`src/api/client.ts`), без `!` и `as`; ответу 204 `unwrap` не нужен.
- **Мутации** — только `useAdminMutation(fn(vars, idempotencyKey))`: ключ идемпотентности — один на действие, `retry()` повторяет с тем же ключом; сам клиент ключ не создаёт (M6). `networkMode: 'always'` — офлайн не копится.
- **Фоновые опросы** (счётчики, статус импорта) — только с `...background()` (возвращает лишь `{ headers }`): заголовок `X-WF-Background: 1` не продлевает сессию. `401 auth.reauth_required` фонового запроса, как и любого, открывает разблокировку (§9.3: через 20 минут бездействия вкладка показывает модалку, а не замёрзший счётчик); открыта уже — запрос ждёт её же, второй раз не открывает.
- **Черновики форм** — `useDraft(<путь маршрута>)` (sessionStorage); пароли и коды в черновик не класть.
- **Токены** — только `--wf-*`; `text-faint` — только плейсхолдеры и неактивные иконки (контраст), подписи — `text-subtle`; `text-ghost` — только disabled; `breakpoint-mobile` — ширина переключения раскладки (в `@media` — через `tokens.ts`).
- **Тесты** — `renderWithProviders(ui, { me })` / `providers({ me })` из `src/test/render.tsx` (me в кэше; `me: null` — тест сам мокает `GET /v1/staff/me`), ответы `me` — `src/test/me.ts`, ошибки — `problem()` из `src/test/problem.ts`. Компонент `src/ui` без API и сессии — `renderWithIntl(ui, { locale })` (язык и тосты, возвращает `user`); с `vi.useFakeTimers()` события — `fireEvent`: user-event зависает (RTL ждёт настоящий `setTimeout`). Телефон — `vi.stubGlobal('matchMedia', …)` с `matches: true` (без matchMedia раскладка широкая); каркас с модератором запрашивает `GET /v1/geo/cities` (названия его городов) — мок в тесте (`src/app/router.test.tsx`).
