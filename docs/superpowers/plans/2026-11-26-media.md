**Goal:** механизм `media` целиком по §12a спеки — без настоящих владельцев (первый — план `economy`):
- **хранилище:** `platform/blob` с бакетами, `Head`, `PutOptions`, подписью (`Presigner`) и сбросом кэша (`Purger`);
  S3-реализация; FS-эмуляция подписанных ссылок для dev и e2e; режим `none` для стенда; остатки фундамента по FS;
- **модуль `media`:** реестр целей, билеты загрузки, `media/intx` (прикрепление, прямая загрузка, открепление,
  снятие), конвейер `media.process` (тип по содержимому, бомбы, EXIF и ICC, варианты WebP, Lottie по
  схеме-разрешению), `media.purge`, чистка, сверка `worker media reconcile`, подписчик удаления аккаунта, события,
  представление `media_read_objects`, лимиты и квота;
- **контракт:** общие схемы `UploadRequest`, `UploadTicket`, `MediaImage`, `PrivateMediaLink` (public и admin);
- **тестовые цели** `e2e_image` (публичная) и `e2e_image_private` с ручками «начать / завершить / показать закрытое /
  прямая загрузка / снять» — только в сборке `wf_e2e`; живой e2e на FS и на настоящем S3-сервере;
- **развёртывание:** `deploy/server` — сервер хранилища, бакеты, ключи, Caddy (домен медиа и адрес хранилища),
  бэкап и сверка; стенд Render — `none`.

**Не здесь:** настоящие цели владельцев (`pitch_photo`, `catalog_asset`, `catalog_animation`, `dispute_evidence`,
`report_evidence`, `support_attachment`, `share_card`) — их регистрируют планы владельцев вместе со своими ручками,
парами `archtest.IntxPairs`, кодами в `x-error-codes` операций и строками `errors.media.*` в локалях фронтов (R11,
R18). Экраны админки для ассетов и плеер Lottie — план `economy`. Веб-клиент загрузки (BFF) — спека веба. CDN — не
подключаем (R10).

## Итоги спайка (Task 1, 26.11.2026) — поправки к R

Отчёт: `.superpowers/sdd/2026-11-26-media/spike.md` (Garage v2.6.0 и Caddy 2.11.9 в Docker, проверка WebP libwebp 1.5.0).

- **R1:** имена бакетов S3 — `wf-in`, `wf-pub`, `wf-priv` (`in` короче 3 символов — Garage отвечает 400); в FS и Memory внутренние имена `in`/`pub`/`priv` остаются. Lifecycle и CORS ставит только ключ с `owner` — служебный ключ init-шага, процессам не выдаётся.
- **R3:** подтверждено (N байт — 204; N±1, чужой/отсутствующий тип, чужой ключ, истёкший срок — 400; 50 МиБ отвергнуто за 28 мс без записи). `PresignPostObject` **не кладёт `Content-Type` в поля формы** — `PresignUpload` добавляет его сам.
