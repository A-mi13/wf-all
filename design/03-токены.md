# Токены

Стартовый набор. Это не финальная палитра, а каркас: конкретные значения
подбираются в дизайне, но структура и имена должны остаться — по ним потом
генерятся переменные для Next.js, Flutter и админки.

Правило одно: ни одного цвета и отступа мимо токенов. Полноценная дизайн-система
сейчас преждевременна, но токены нужны сразу, иначе три клиента разъедутся.

## Цвет

Семантические имена, не «зелёный». Тёмная тема основная, светлая производная.

```
--bg              фон приложения
--bg-elevated     карточка, шит
--bg-sunken       поле ввода, вдавленный блок
--border
--border-strong

--text            основной
--text-muted      второстепенный
--text-inverse    на акцентной заливке

--accent          единственный яркий цвет, один на весь продукт
--accent-hover
--accent-muted    фон чипа, полосы прогресса

--success         состав собран, оплачено
--warning         мало времени, мало людей
--danger          отмена, неявка, бан
--info

--pitch           заливка схемы поля
--pitch-line      разметка
--slot-empty      свободная позиция
--slot-filled     занятая позиция
```

Акцент один. Соблазн раскрасить формат матча в разные цвета нужно задавить:
на ленте из двадцати карточек это превращается в кашу.

## Типографика

Один шрифт, гротеск, обязательно с плотным начертанием для цифр.
Цифры табличные (`tabular-nums`) — иначе счёт и статистика будут прыгать.

```
--font-display    крупные цифры: счёт, статистика, места в таблице
--font-body

--text-3xl   32 / 36   счёт матча, число в карточке игрока
--text-2xl   24 / 30   заголовок экрана
--text-xl    20 / 28   название команды, матча
--text-lg    18 / 26
--text-base  16 / 24   основной
--text-sm    14 / 20   подписи, метаданные
--text-xs    12 / 16   бейджи
```

Меньше 12 не опускаться: экран читают на улице.

## Отступы

Шаг 4. Ничего мимо шкалы.

```
--space-1   4      --space-6   24
--space-2   8      --space-8   32
--space-3   12     --space-10  40
--space-4   16     --space-12  48
--space-5   20     --space-16  64
```

Боковое поле экрана — 16. Внутренний отступ карточки — 16, между карточками — 12.

## Радиусы и тени

```
--radius-sm    8     чип, бейдж
--radius-md    12    поле ввода, кнопка
--radius-lg    16    карточка
--radius-xl    24    шит снизу
--radius-full        аватар, круглая кнопка

--shadow-card
--shadow-sheet
```

В тёмной теме тени почти не работают — разделяй слои фоном (`--bg-elevated`),
а не тенью.

## Размеры

```
--touch-min     44    минимальная цель нажатия
--avatar-sm     32
--avatar-md     48    состав, лента
--avatar-lg     96    карточка игрока
--slot-size     56    кружок позиции на схеме поля
--bar-height    8     полоса заполнения состава
```

## Движение

```
--duration-fast    120ms   нажатие, переключатель
--duration-base    200ms   появление шита, переход
--duration-slow    400ms   разворот карточки лидера
--ease             cubic-bezier(0.2, 0, 0, 1)
```

Анимации две и обе осмысленные: заполнение полосы состава и разворот карточки
первого места в таблице. Остальное — мгновенное. Уважай
`prefers-reduced-motion`.

## Что описать компонентами

Кнопка (основная, вторичная, опасная, отключённая), поле ввода с ошибкой,
чип фильтра, карточка матча, карточка команды, аватар с рамкой, бейдж
(тип матча, возраст, новичок), полоса прогресса, пустое состояние с иллюстрацией,
шит снизу, кружок позиции на схеме поля в трёх состояниях: свободен,
занят, забронирован.
